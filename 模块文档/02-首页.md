# 模块文档 02：首页（Hero 开场）

> 版本：v1.0　日期：2026-08-11　路由：`/`　MVP：仅 Hero 开场

## 1. 模块职责

网站开场封面：展示**队徽**与站点信息，引导用户进入核心的地图页。MVP 仅此一个区块，其余（精神主线/场馆速览/时间线预览）砍掉。

## 2. 页面结构

```
src/pages/HomePage.tsx  +  HomePage.module.css
└── HeroSection.tsx     +  HeroSection.module.css
```

## 3. 布局与内容

**整体**：全屏（`min-height: 100vh`）居中排版，深红渐变背景（`#7B241C → #B03A2E`），可加金色纹样/光斑点缀。

**左侧：队徽**
- 使用队徽 `/brand/duihui.png`（512×512 透明底，源自 `队徽.png`，已生成）
- 品牌图形统一用队徽，不使用队旗
- 尺寸：队徽约 200-260px 见方，`<img loading="lazy">` 或直接内联

**右侧：文字区**
- 主标题：**"铁军精神·驻地变迁"**（已定），思源宋体大字号
- 副标语："踏四省红色热土，传百载铁军薪火"（队名"铁军寻脉实践团"可作辅助署名）
- 一段一句话简介（可选）

**底部：进入地图按钮**
- 主 CTA："进入地图"（`→` 图标），金色/米黄描边样式
- 点击 → `useNavigate('/map')`
- 辅助：滚动指示器（↓ 动画，提示向下滚动）

## 4. 交互与过渡

- 进场动画（可选）：标题/副标语淡入上浮（Framer Motion `motion`，错峰 0.2s）
- 点击"进入地图"：触发全局路由过渡（淡入淡出）到 `/map`
- 向下滚动：当 `window.scrollY > 视口高度一半` 时也触发进入地图（避免误触，需有明确意图或仅作提示，可先只做按钮触发）

## 5. 数据依赖

- 无 content 数据依赖（队徽为静态资源）
- 站点名/副标语当前硬编码于组件，后续如需可放入 content（二期）

## 6. 样式要点（HeroSection.module.css）

- 背景渐变 + 居中 flex 布局
- 队徽与文字左右分栏（flex 或 grid 两列），间距响应 `gap`
- 主标题大字号（约 56-72px），副标语约 20-24px，颜色米黄/白
- 按钮：`--c-gold` 描边，hover 填充过渡
- 滚动指示：底部居中，上下浮动动画（CSS keyframes）
