# 模块文档 01：全局骨架

> 版本：v1.0　日期：2026-08-11　归属模块：全站通用　MVP 范围：仅桌面版

## 1. 模块职责

提供全站统一的骨架：导航栏、页脚、主题样式、字体、页面过渡与路由框架。所有页面共享，不承载具体业务内容。

## 4. 主题变量（styles/theme.css）

> 视觉方向详见《设计方向.md》——"红色文献·铁军档案"（纸张质感、印章图形、思源宋/楷/黑字体、仪式感动效）。

```css
:root {
  --c-primary:   #B03A2E;   /* 主红 */
  --c-deep:      #7B241C;   /* 深红 */
  --c-gold:      #C9A227;   /* 金 */
  --c-bg:        #F7F1E3;   /* 米黄背景 */
  --c-text:      #2C2C2C;   /* 墨色文字 */
  --c-text-light:#6b6b6b;
  --font-title:  'Noto Serif SC', 'Songti SC', serif;
  --font-body:   'Noto Sans SC', 'Microsoft YaHei', sans-serif;
  --gap: 16px;              /* 基础间距 */
  --radius: 8px;
}
```

全局样式要点：
- `* { box-sizing: border-box }`，`body` 设背景 `var(--c-bg)`、正文色 `var(--c-text)`、字体 `var(--font-body)`
- 标题默认 `font-family: var(--font-title)`
- 全局滚动条/选中色可统一为红色调

## 7. 路由与页面过渡（App.tsx）

```tsx
const routes = [
  { path: '/', Component: lazy(() => import('./pages/HomePage')) },
  { path: '/map', Component: lazy(() => import('./pages/MapPage')) },
  { path: '/venues/:id', Component: lazy(() => import('./pages/VenueDetailPage')) },
  { path: '/gallery', Component: lazy(() => import('./pages/GalleryPage')) },
  { path: '/guestbook', Component: lazy(() => import('./pages/GuestbookPage')) },
  { path: '/achievements', Component: lazy(() => import('./pages/AchievementsPage')) },
];
```

过渡实现：
- `<AnimatePresence mode="wait">` 包裹，key = `location.pathname`
- 进入/离开：`opacity: 0→1` + 轻微 `y: 8→0`，时长约 0.3s
- 配合 `Suspense` fallback（全屏深红/米黄背景），避免懒加载闪白
- 部署用 HashRouter（GitHub Pages 无 fallback）
