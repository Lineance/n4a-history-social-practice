# 模块文档 05：调研集锦页

> 版本：v1.0　日期：2026-08-11　路由：`/gallery`　MVP：仅瀑布流照片墙（时间线/总结延后）

## 1. 模块职责

集中展示实地调研照片，作为"社会实践实际调研集锦"。MVP 只做瀑布流照片墙。

## 2. 页面结构

```
src/pages/GalleryPage.tsx   + GalleryPage.module.css
├── 页头：标题（"调研集锦"）+ 说明文字
└── PhotoWall.tsx           + PhotoWall.module.css
```

## 3. 照片数据来源

- 从 `content/visits/*.md` 或直接约定资源目录 `public/images/visits/<地点>/`
- **MVP 数据组织建议**：用 `content/visits/*.md`（各地点一个），frontmatter 含 `images: string[]` 与 `location`；解析后合并为照片列表
- 若无 `visits` 内容，可先扫描静态目录约定（开发时确认一种即可）

## 4. 瀑布流实现（PhotoWall）

- 纯 CSS：`columns: 4 240px`（`column-width` 自适应），容器 `column-gap`
- 每张图片容器 `break-inside: avoid`
- 响应数量：固定 3-4 列即可（桌面 MVP）
- 图片：`<img loading="lazy">`，WebP 已压缩，占位背景色防布局抖动

## 5. 灯箱

- 点击图片 → 打开共用 `Lightbox`（`components/common/Lightbox.tsx`）
- 传入全部照片作为 slides，支持左右切换

## 6. 照片说明

- 缩略图下显示 `caption`（来自 visit 记录的图片说明或默认"<地点> 调研"）
- 可按图片 EXIF 时间排序（可选，一期可不做）

## 7. 延后区块（二期）

- 调研时间线（`content/visits/` 的 `notes` 见闻文字按日期排）
- 调研总结段落

- [ ] 图片懒加载，滚动流畅
