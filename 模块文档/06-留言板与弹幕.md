# 模块文档 06：留言板 + 弹幕

> 版本：v1.0　日期：2026-08-11　路由：`/guestbook`（留言板）+ 地图页内弹幕　MVP：Giscus 占位 + 预置留言弹幕

## 1. 模块职责

访客留言互动。两种形态：
1. **留言板页 `/guestbook`**：嵌入 Giscus（GitHub Discussions 为后端）
2. **地图页弹幕蒙版**：以弹幕形式展示留言，作为氛围装饰

## 2. 文件与组件


## 3. 留言板页（Giscus）

### 3.1 前置条件（团队待办）
1. 创建公开 GitHub 仓库
2. 仓库 Settings → General → **启用 Discussions**
3. 安装 [Giscus App](https://github.com/apps/giscus) 到仓库
4. 在 [giscus.app](https://giscus.app) 配置，取得 `data-repo`、`data-repo-id`、`data-category`、`data-category-id`

### 3.2 配置化
- 四个参数放统一配置（如 `src/config.ts` 或环境变量），便于仓库就绪后一键替换
- 仓库未配置时：渲染 `GiscusPlaceholder`（"留言功能筹备中" + 引导文案）

### 3.3 组件实现（GiscusEmbed）

```tsx
export function GiscusEmbed() {
  const config = useGiscusConfig();
  useEffect(() => {
    if (!config) return;
    const script = document.createElement('script');
    script.src = 'https://giscus.app/client.js';
    script.async = true;
    script.setAttribute('data-repo', config.repo);
    script.setAttribute('data-repo-id', config.repoId);
    script.setAttribute('data-category', config.category);
    script.setAttribute('data-category-id', config.categoryId);
    script.setAttribute('data-mapping', 'pathname');
    script.setAttribute('data-strict', '0');
    script.setAttribute('data-reactions-enabled', '1');
    script.setAttribute('data-emit-metadata', '0');
    script.setAttribute('data-theme', 'light');
    script.setAttribute('data-lang', 'zh-CN');
    ref.current?.appendChild(script);
    return () => { ref.current?.querySelectorAll('script').forEach(s => s.remove()); };
  }, [config]);
  return <div ref={ref} />;
}
```

页面要求：留言板页内文案（"欢迎留下对铁军精神的感悟"）+ 评论区容器。

## 4. 弹幕蒙版（DanmakuLayer）

### 4.1 数据源（MVP：预置留言）
- `content/testimonials.md` → `texts: string[]`
- 解析后由 `lib/content.ts` 导出 `testimonialTexts`
- 示例文案：铁军精神永放光芒 / 传承红色基因，赓续铁军血脉 / 向革命先烈致敬 / 踏四省红色热土……

### 4.2 交互
- **默认关闭**；地图页角落"弹幕"按钮（`pointer-events: auto`），点击切换开/关
- 开启：留言从右侧向左横向飘过，多条错峰、不同纵向轨道
- 提供"暂停/继续"（可选）

### 4.3 实现要点
- 浮层 `position: absolute; inset: 0; overflow: hidden; pointer-events: none;`
- 每条弹幕为一个绝对定位的 `<span>`，CSS `animation: danmaku 12s linear`（`transform: translateX(100vw→-100%)`）或 Framer Motion 驱动
- 弹幕样式：半透明底 `rgba(0,0,0,0.35)` + 米黄/白描边字，圆角，适配红色主题
- 轨道：按播放序号取 4-6 条固定 `top` 值，避免重叠
- 卸载/关闭时清除定时器与动画
