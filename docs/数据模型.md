# 数据模型文档

> 版本：v1.2　日期：2026-08-11　配套文档：《方案.md》《需求文档.md》《技术方案.md》

内容与代码分离原则：**所有展示内容以结构化文档（Markdown + frontmatter）形式存放于 `content/`**，页面组件只负责渲染。frontmatter 中的 YAML 字段遵循本文档定义的 schema（对应 TS 接口，用于解析与校验）。

## 2. Frontmatter 字段规范（对应 TS 接口）

### 2.1 Venue（场馆，`content/venues/*.md`）

frontmatter 示例：
```yaml
---
id: hankou
cover: /images/venues/hankou/cover.webp
name: 汉口新四军军部旧址纪念馆
shortName: 汉口
city: 湖北武汉
coords:
  lat: 30.60884
  lng: 114.30561
periodKey: hankou
dates:
  from: "1937-12-25"
  to: "1938-01-04"
address: 湖北省武汉市江岸区胜利街 332-352 号
spiritTags: [举旗定向, 听党指挥, 政治智慧]
website: https://www.whbb.org.cn/
visitStatus: offline
onMap: true
displayOrder: 1
images:
  - src: /images/venues/hankou/01.webp
    caption: 旧址外景
    source: field
---
<正文：场馆简介>
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| id | string | 是 | 路由用，唯一，如 `hankou` |
| cover | string | 是 | 卡片/资料卡主效果图路径（`/images/venues/<id>/cover.webp`） |
| name | string | 是 | 场馆全名 |
| shortName | string | 是 | 简称，地图卡片用 |
| city | string | 是 | 城市，如 `湖北武汉` |
| coords | {lat, lng} | 是 | 真实经纬度（街道级核实） |
| periodKey | string | 是 | 关联时期 key |
| dates | {from, to} | 是 | 日期区间 |
| address | string | 是 | 详细地址 |
| spiritTags | string[] | 是 | 铁军精神关键词 |
| website | string | 否 | 官网 URL |
| visitStatus | enum | 是 | `offline`（线下）/ `online`（线上）/ `noVenue`（旧址无馆）/ `pending`（后续实践） |
| onMap | boolean | 否 | 是否在地图上打点；缺省 true（梅园为 false） |
| displayOrder | number | 是 | 展示顺序 |
| images | {src, caption, source}[] | 是 | 图集图片列表；source ∈ `field`/`official`/`public` |

> 实践状态徽标：`offline`=朱砂印"线下实践"、`online`=金印"线上实践"、`noVenue`=灰虚线"旧址无馆"、`pending`=灰描边"后续实践"。`noVenue` 场馆封面为米黄占位图（"旧址尚存 · 暂无纪念馆"），待后续考证补充。

### 2.2 TimelinePeriod（时期，`content/timeline/*.md`）

frontmatter 示例：
```yaml
---
key: hankou
title: 汉口时期
subtitle: 举旗定向
dates:
  from: "1937-12-25"
  to: "1938-01-04"
venueIds: [hankou]
summary: 新四军军部诞生地，完成组织筹备与领导机构建立。
spiritNote: 体现了“跟党举旗”的政治智慧与听党指挥的坚定信念。
accentColor: "#C0392B"
---
<正文：时期详述（可选）>
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| key | string | 是 | 时期唯一标识 |
| title | string | 是 | 时期标题 |
| subtitle | string | 是 | 主题短语 |
| dates | {from, to} | 是 | 日期区间 |
| venueIds | string[] | 是 | 关联场馆（多数为 1 个） |
| summary | string | 是 | 时间轴滑块侧栏摘要 |
| spiritNote | string | 是 | 铁军精神表现说明 |
| accentColor | string | 否 | 地图标记配色 |

### 2.3 HistoricalEvent（事件，`content/events/*.md`）

**一馆一文件**：每个场馆一个文件（`01-hankou.md`、`02-nanchang.md`…，编号与场馆顺序一致），该馆全部历史事件集中在文件正文，按 `## 日期 · 标题` 的 Markdown 二级标题分区。

frontmatter 示例：
```yaml
---
venueId: nanchang
---
## 1938-01-06 · 军部正式迁驻南昌并全面运转
<事件详细叙述>

## 1938-01 · 南方八省红军游击队完成集结整编
<事件详细叙述>
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| venueId | string | 是 | 所属场馆 |
| 正文标题 | `## 日期 · 标题` | 是 | 每个事件一个小节，日期与标题以 `·` 分隔 |

解析约定：读取 frontmatter 得 `venueId`；正文按二级标题切分为多个事件（标题解析出 date + title，节内容为叙述）。

### 2.4 VisitRecord（调研记录，`content/visits/*.md`）

frontmatter 示例：
```yaml
---
id: yunling-2026
venueId: yunling
date: "2026-07-25"
location: 泾县云岭镇罗里村
images:
  - /images/visits/yunling/01.webp
---
<正文：见闻与感悟>
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| id | string | 是 | 唯一 |
| venueId | string | 是 | 关联场馆 |
| date | string | 是 | 调研日期 |
| location | string | 是 | 地点 |
| images | string[] | 是 | 照片路径列表 |
| 正文 | text | 是 | 见闻/感悟 |

### 2.5 Testimonial（弹幕留言，`content/testimonials.md`）

用于地图主页弹幕蒙版的预置留言（保底方案，不依赖 Giscus 拉取）。

格式示例：
```markdown
---
texts:
  - 铁军精神永放光芒
  - 传承红色基因，赓续铁军血脉
  - 向革命先烈致敬
---
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| texts | string[] | 是 | 弹幕文案列表，循环播放 |

> 若后续接入真实留言（GitHub GraphQL 拉取），本文件作为降级兜底保留。

### 2.6 AchievementSection（成果页，`content/achievements.md`）

成果页所有分区集中在一个文件，按 frontmatter `sections` 数组渲染。

格式示例：
```yaml
---
sections:
  - title: 公众号推文
    desc: 系列调研纪实（微信公众号 · 铁军寻脉实践团）
    ready: true
    links:
      - title: 从汉口到南昌：一支军队的底色与规矩
        platform: wechat
        image: /images/achievements/weixin-01.webp
        url: https://mp.weixin.qq.com/s/xxxx
  - title: 图文笔记
    desc: 调研手记（小红书 · 东南大学铁军寻脉实践团）
    ready: true
    links:
      - title: 汉口→南昌｜探访新四军最初的诞生之地
        platform: xiaohongshu
        url: https://www.xiaohongshu.com/discovery/item/xxxx
  - title: 视频
    desc: 调研纪实视频（哔哩哔哩 · 铁军寻脉实践团）
    ready: true
    links:
      - title: 踏四省红色热土，传百载铁军薪火
        platform: bilibili
        image: /images/achievements/bili-01.webp
        url: https://www.bilibili.com/video/BVxxxx/
        douyin: ''
  - title: 调研报告
    desc: 社会实践调研报告（整理中）
    ready: false
---
```

> 按媒体平台/媒介形态拆分为多个栏目（如公众号推文、图文笔记、视频），同一类型新增内容直接往对应 `links` 追加即可。

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| sections[] | array | 是 | 分区列表，按数组顺序渲染 |
| sections[].title | string | 是 | 分区标题 |
| sections[].desc | string | 是 | 分区说明 |
| sections[].ready | boolean | 是 | 是否已就绪；false 显示"内容整理中…"占位 |
| sections[].links[] | array | 否 | 媒体卡片列表（微信推文、小红书笔记、视频等） |
| links[].title | string | 是 | 卡片标题 |
| links[].url | string | 是 | 主平台外链地址（https） |
| links[].platform | enum | 是 | `wechat` / `xiaohongshu` / `bilibili` / `douyin` |
| links[].image | string | 否 | 封面本地路径 `/images/achievements/<slug>.webp`（WebP ≤300KB，缺省用品牌占位） |
| links[].douyin | string | 否 | 视频第二平台（抖音）链接；空字符串 = 待发布，卡片显示禁用按钮 |

> 视频卡：`platform: bilibili` 且声明 `douyin` 字段（可为空串）时渲染「B站播放 / 抖音」双按钮。
> 封面需本地化（WebP ≤300KB，放 `public/images/achievements/`），新增成果直接编辑本文件即可。

## 5. 历史事件清单（`content/events/`）

### 汉口
- 1937-12-25：新四军军部在汉口大和街26号正式成立
  - 内容：叶挺、项英、张云逸召开干部大会；解决编制、干部任命、防区、军费等；下辖4支队1特务营共1.03万余人；1938年1月4日项英率部离汉赴南昌。

### 南昌
- 1938-01-06：军部迁南昌三眼井（原张勋公馆）全面运转，东南分局成立
- 1938-01~03：南方八省红军游击队完成集结整编（4支队10团1教导营）
- 1938-01-10：项英提出"十条军规"，后发展为"三大纪律、十项注意"
- 1938-04-04：军部离南昌赴岩寺，数千市民车站欢送

### 岩寺
- 1938-04-05：军部由南昌迁皖南歙县岩寺，完成最后集中点验整编
- 1938-04-28：粟裕率先遣支队从岩寺出发东进，揭开东进抗日序幕
- 1938-05-05：军部离开岩寺向太平县转移

### 云岭
- 1938-08-02：军部进驻泾县云岭，驻扎两年半，全军发展至9万余人
- 1941-01-04~14：皖南事变——9000余人遭8万国民党军围攻，激战七昼夜，仅约2000人突围；叶挺被囚写"富贵不能淫"；1月20日中央重建军部，陈毅代军长、刘少奇政委。

### 盐城
- 1941-01-20：中共中央发布重建新四军军部命令
- 1941-01-25：军部重建大会在盐城游艺园举行，整编为7师1独立旅（9万余人），设计"N4A"臂章

### 停翅港
- 1941-07~08：日伪军1.7万人"扫荡"盐城，军部撤至阜宁停翅港（朱太俊16间茅草屋）
- 1942：创办"文化村"与"湖海艺文社"，陈毅手书"英雄帖"邀文化名人
- 1942-12-25：军部撤出停翅港，向淮南黄花塘转移（驻扎一年零三个月）

### 黄花塘
- 1943-1945：军部与华中局驻黄花塘（驻留时间最长直至抗战胜利），开展整风、大生产运动

### 梅园
- 1946：中共代表团南京谈判，新四军骨干力量在政治战场延续铁军意志

## 8. 校验规则

- 每个 `venue.id` 唯一，且必须存在于 `timeline` 某时期的 `venueIds` 中
- 每个 `event.venueId`、`visit.venueId` 必须指向存在的场馆
- 地图页使用 `coords`，坐标范围应在中国境内，且为**街道级核实值**（放大定位精度要求）
- `provinces.json` 需含鄂/赣/皖/苏四省边界，GeoJSON 合法
- 所有图片路径必须真实存在，且已压缩（避免 5MB+ 大图直接引用）
- frontmatter 解析后需通过 TS 接口类型校验（开发期在解析层断言）
