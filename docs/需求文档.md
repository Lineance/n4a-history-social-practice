# 详细需求文档

> 版本：v1.2　日期：2026-08-11　配套文档：《方案.md》《数据模型.md》《技术方案.md》

本文档逐页面描述功能需求、交互细节与内容要求，是开发与验收的依据。

## 0. 全局需求（所有页面通用）

### 0.1 导航栏
- 顶部固定导航，包含：首页、交互地图、调研集锦、留言板、成果
- 场馆入口**不放导航**，由地图页侧栏列表与悬停资料卡进入详情页
- 高亮当前页面对应导航项
- 品牌区：站点名称（含"铁军精神"标识）

### 0.2 页脚
- 实践团队信息、立项答辩信息、备案/版权声明
- 重要参考资料链接（场馆官网）
- 联系方式（可选）

### 0.3 视觉风格（红色主旋律）
- 主色：革命红（#B03A2E 主红 / #7B241C 深红），辅以金（#C9A227）、米黄（#F7F1E3 背景）、墨色文字（#2C2C2C）
- 字体：标题用思源宋体（Noto Serif SC），正文用思源黑体（Noto Sans SC），经 `@fontsource` 自托管打包
- 统一按钮、卡片、分隔线样式（CSS Modules 变量管理）

### 0.4 响应式（MVP：仅桌面版）
- **只做桌面版**，不做移动端/平板适配，无汉堡菜单、无底部抽屉
- 地图页采用桌面布局（地图 + 侧栏）

### 0.5 性能
- 所有图片使用压缩后的 WebP（单张 ≤300KB），懒加载
- 路由级代码分割，首屏只加载必要 JS
- 品牌图形统一用队徽（`/brand/duihui.png`，已由 `队徽.png` 生成），不用队旗

### 0.6 页面过渡
- 路由切换使用淡入淡出过渡动画（Framer Motion），全站统一

## 2. 交互地图 `/map`（核心页面）

### 2.1 地图主体
- 使用 **MapLibre GL + OpenFreeMap 矢量瓦片**（真实矢量地图，可手动缩放至街道级查看场馆具体位置）
- 中国区域居中，初始视野包住各标记点范围
- 底图浅色样式为基础，叠加红色主题配色
- 四省（鄂/赣/皖/苏）省界用 GeoJSON 半透明红色填充强调（山东的临沂照常打点，不纳入省界高亮）
- 10 个场馆（梅园除外）按**街道级经纬度**打点（开发时核实真实地址坐标）；未实践（旧址无馆/后续实践）场馆用灰色描边标记

### 2.2 标记点
- GeoJSON source + **circle 图层**（矢量红点），配合脉冲动画
- 不同时期用不同颜色/透明度区分；当前选中/激活时期高亮（放大+金色）
- 标记可 hover / 点击

### 2.3 悬停资料卡（核心交互）
- 鼠标悬停标记 → 弹出资料卡
- 资料卡内容：场馆名、时期、日期区间、一句话简介、缩略图、铁军精神关键词、"查看详情"链接（跳 `/venues/:id`）
- 卡片需视觉遮挡处理，靠近边缘时不超出视口

### 2.4 时间轴滑块
- 页面底部/侧边时间轴：汉口→南昌→岩寺→麻村→土塘→云岭→盐城→停翅港→黄花塘→千棵柳→淮阴→临沂→梅园
- 滑块状态联动地图：
  - 地图自动缩放/居中到该时期场馆
  - 只高亮该时期相关标记，其余淡化
  - 侧边同步显示该时期文字摘要与精神关键词
- 支持点击年份节点直接跳转
- 初始定位：读取 URL query 参数 `?period=<key>`（如 `/map?period=yunling`），进入页面即定位到对应时期

### 2.5 飞线动画
- 技术：GeoJSON 线图层 + **动画 dash / rAF 移动光点**（MapLibre 图层实现）
- 触发：**进入地图页自动播一遍**完整驻地变迁（汉口→…→临沂，梅园不参与）飞线轨迹；拖动时间轴滑块时触发当前段的单段飞线
- 动画需可关闭/重播，避免干扰浏览

### 2.6 场馆列表侧栏
- 地图旁/下方列出 13 场馆，点击定位到对应标记并弹出卡片

### 2.7 弹幕蒙版（留言板联动）
- 地图页角落设"弹幕"开关按钮，**默认关闭**，点击开启/关闭
- 开启后留言以弹幕形式从屏幕一侧缓慢飘过（内容为预置留言，见 §6.1）
- 弹幕为半透明浮层，不遮挡标记点与时间轴交互；可暂停/隐藏

## 6. 留言板 `/guestbook`

**双通道留言墙**（本地留言 + GitHub 评论区）：

- **本地留言墙（始终可用，无需配置）**：
  - "铁军寄语"区：展示 `content/testimonials.md` 预置文案（楷体引文卡片）
  - "访客留言"区：输入框（仅内容，≤200 字 + 字数提示，Enter/按钮提交），留言存 **localStorage**（key `n4a_messages`，上限 50 条，try/catch 容错）
  - 新留言即时上墙、刷新保留（本机）；实现见 `src/lib/localMessages.ts` + `components/guestbook/MessageWall.tsx`
- **GitHub 评论区（Giscus）**：`src/config.ts` 的 `giscus.repo` 配置后显示（登录 GitHub 可留言）；未配置时隐藏
- 提供留言引导文案（"欢迎留下对铁军精神的感悟"）

### 5.1 地图主页弹幕蒙版

留言板路由保留，同时在地图主页以**弹幕（danmaku）蒙版**形式展示留言，作为页面氛围装饰。

- 弹幕内容来源：**预置留言 + 本地访客留言**（`testimonialTexts` ∪ localStorage，见 `src/lib/localMessages.ts#allMessageTexts`）；Giscus 真实评论拉取二期再考虑
- 表现形式：留言以弹幕方式从屏幕一侧飘过（字幕式、缓慢横向滚动）
- 视觉要求（美观优先）：
  - 半透明浮层，不遮挡地图关键交互（标记点、时间轴）
  - 字体、颜色适配红色主题（可用白/米黄半透明描边字）
  - 速度慢、间隔均匀，避免杂乱；可暂停/隐藏
  - 触发方式：**开关按钮控制，默认关闭**（地图页角落按钮），开启时读取最新留言
- 交互边界：弹幕蒙版不可阻挡地图点击
- 技术备注：弹幕数据来自预置留言 + 本地留言（见《数据模型.md》§2.5 与 `localMessages.ts`）；Giscus 真实评论拉取二期再议
