# 模块文档 07：成果页

> 版本：v1.2　日期：2026-08-16　路由：`/achievements`　数据：`content/achievements.md`

## 1. 模块职责

展示社会实践项目最终成果。分区与内容由 `content/achievements.md` 驱动，媒体以**图片卡片**呈现（封面 + 平台徽标 + 点击跳转），数据不在组件内硬编码。

## 2. 页面结构

```
content/achievements.md               分区数据（frontmatter: sections[]）
public/images/achievements/           封面图（本地 WebP ≤300KB）
src/lib/content.ts                    parseAchievements() + achievements 导出
src/types/content.ts                  AchievementSection / AchievementLink / AchievementPlatform
src/components/achievements/MediaCard.tsx + .module.css  单张媒体卡片
src/pages/AchievementsPage.tsx + AchievementsPage.module.css
└── 分区（标题 + 描述 + 卡片网格）
```

## 3. 分区 schema（见 数据模型.md §2.6）

| 字段 | 类型 | 说明 |
|------|------|------|
| `sections[].title` | string | 分区标题（如 公众号推文） |
| `sections[].desc` | string | 分区说明 |
| `sections[].ready` | boolean | 是否已就绪（false 显示占位） |
| `sections[].links[]` | array | 媒体卡片列表 |
| `links[].title` | string | 卡片标题 |
| `links[].url` | string | 主平台外链（https） |
| `links[].platform` | enum | wechat / xiaohongshu / bilibili / douyin |
| `links[].image` | string? | 封面本地路径 `/images/achievements/<slug>.webp` |
| `links[].douyin` | string? | 视频第二平台；空串 = 待发布（禁用按钮） |

> 媒体内容按平台/媒介拆分为多个栏目（公众号推文、图文笔记、视频），各自一个分区。

## 4. 实现要点

- 页面从 `import { achievements } from '../lib/content'` 读取，每分区渲染标题 + `auto-fill` 卡片网格
- **MediaCard**：
  - 封面 `<img loading="lazy">`；无 `image` → 平台色品牌占位（深红渐变 + 楷体平台名）
  - hover 上浮 + 金色描边（§7）
  - 整卡可点击 → 主平台 `url`（`role="link"` + `tabIndex` + Enter/Space 键盘可达）
  - **视频卡**（`platform: bilibili` 且声明 `douyin` 字段）：底部「B站播放」「抖音」双按钮，`stopPropagation` 防冒泡；`douyin` 为空串 → 抖音按钮禁用并标"敬请期待"
- 外链一律 `target="_blank"` + `rel="noreferrer"`；封面解析时经 `assetUrl` 加 base 前缀
- `ready=false` 渲染"内容整理中…"占位
- 字段缺失/类型错误在解析层抛错（开发期暴露）

## 5. 数据来源

- `content/achievements.md`，字段严格按 `docs/数据模型.md §2.6`
- 封面本地化：抓取平台封面 → 压缩为 WebP（宽 ≤1600、≤300KB）放入 `public/images/achievements/`，更新 `image` 字段
- 新增成果（PDF、媒体报道、抖音视频等）直接编辑对应栏目
