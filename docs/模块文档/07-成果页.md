# 模块文档 07：成果页

> 版本：v1.1　日期：2026-08-16　路由：`/achievements`　数据：`content/achievements.md`

## 1. 模块职责

展示社会实践项目最终成果。分区与内容由 `content/achievements.md` 驱动，数据（标题、描述、媒体链接）不在组件内硬编码。

## 2. 页面结构

```
content/achievements.md        分区数据（frontmatter: sections[]）
src/lib/content.ts             parseAchievements() + achievements 导出
src/types/content.ts           AchievementSection / AchievementLink
src/pages/AchievementsPage.tsx + AchievementsPage.module.css
└── 分区列表（标题 + 描述 + 链接/占位）
```

## 3. 分区 schema（见 数据模型.md 成果页）

| 字段 | 类型 | 说明 |
|------|------|------|
| `sections[].title` | string | 分区标题（如 公众号推文） |
| `sections[].desc` | string | 分区说明 |
| `sections[].ready` | boolean | 是否已就绪（false 显示占位） |
| `sections[].links[]` | array | 媒体链接（微信推文 / PDF 等） |
| `links[].title` | string | 链接显示标题 |
| `links[].url` | string | 外链地址（https） |
| `links[].source` | string? | 来源说明（可省略，平台信息写在 desc） |

> 媒体内容按平台/媒介拆分为多个栏目（公众号推文、图文笔记、视频），各自一个分区。

## 4. 实现要点

- 页面从 `import { achievements } from '../lib/content'` 读取，按顺序渲染分区卡片
- `links` 非空渲染链接列表（`target="_blank"` + `rel="noreferrer"`）
- `ready=false` 渲染"内容整理中…"占位
- 字段缺失/类型错误在解析层抛错（开发期暴露）

## 5. 数据来源

- `content/achievements.md`，字段严格按 `docs/数据模型.md`，后续新增成果（PDF、视频、媒体报道）直接编辑对应栏目即可
