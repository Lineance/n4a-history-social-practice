# 模块文档 07：成果页

> 版本：v1.0　日期：2026-08-11　路由：`/achievements`　MVP：骨架占位

## 1. 模块职责

展示社会实践项目最终成果。MVP 阶段仅建页面骨架与分区标题，内容由团队后续提供后填充。

## 2. 页面结构

```
src/pages/AchievementsPage.tsx  + AchievementsPage.module.css
└── 分区列表（标题 + 空内容占位）
```

## 3. 建议分区（骨架标题）

| 分区 | 占位说明 |
|------|----------|
| 实践概况 | 团队简介、实践主题、覆盖四省八场馆 |
| 调研报告 | 附件/长文入口（PDF 等） |
| 立项答辩 | PPT 下载/在线预览入口（可链接 `立项答辩/ppt初稿.pptx`） |
| 实践记录 | 短视频/图文（如后期产出） |
| 团队成员 | 姓名/分工（可选） |
| 成果与影响 | 数据、媒体报道等（可选） |

## 4. 骨架实现

- 每个分区渲染为"标题 + 说明 + 空状态占位"（虚线框 + "内容整理中…"）
- 有真实文件的分区（如 PPT）可先挂链接，其余留空
- 布局：单列内容流，最大宽度约 960px 居中，分区用卡片分隔

## 5. 数据来源

- MVP：无数据层，标题硬编码于组件
- 二期：如需，可将分区内容做成 `content/achievements.md` 结构化文档

## 6. 验收清单

- [ ] `/achievements` 可访问，各分区标题与占位正常显示
- [ ] 有真实文件的入口可跳转（PPT 等）
- [ ] 无报错，样式与全局主题一致
