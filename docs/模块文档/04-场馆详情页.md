# 模块文档 04：场馆详情页

> 版本：v1.0　日期：2026-08-11　路由：`/venues/:id`　MVP：六块全保留，砍上下页导航

## 1. 模块职责

展示单个场馆的完整信息：基本信息、历史事件、铁军精神体现、照片图集。13 个场馆共用同一模板，数据驱动。

## 2. 页面结构

```
src/pages/VenueDetailPage.tsx   + VenueDetailPage.module.css
└── 区块
    ├── 头部（header，含实践状态徽标）
    ├── 简介（intro）
    ├── 历史事件（events）
    ├── 铁军精神体现（spirit）
    └── 照片图集（photo gallery, images 非空时才有）
```

## 3. 数据获取

- 路由参数 `id`（如 `/venues/hankou`）
- 从 `lib/content.ts` 取：
  - `venue = venues.find(v => v.id === id)`
  - `events = eventsByVenue[id]`（按日期排序）
  - 若 `id` 不存在 → 404/跳回首页
- 加载中：`Suspense` fallback

## 4. 各区块详情

### 4.1 头部
- 场馆名（大字）、城市、时期标题、日期区间
- 主图：`cover`（线下实践用实地照片，线上/敬请期待用占位或公开资料图）
- 角标：实践状态徽标（`visitStatus`，`VisitBadge` 组件：线下/线上/敬请期待）
- 地址（`address`）、官网链接（`website` 存在时，"访问官网 ↗"外链）

### 4.2 场馆简介
- 渲染 `content/venues/{id}.md` 正文（Markdown），或 frontmatter `intro` 字段
- 两栏布局可选：左文右图（场馆外观）

### 4.3 历史事件
- 列表：每条 = 日期徽标（如 `1938-04-05`）+ 标题 + 详述正文
- 来源：`content/events/` 按 `venueId` 关联
- 布局：纵向列表，时间轴感（左侧时间线/竖线）

### 4.4 铁军精神体现
- 独立区块，突出主题色背景（深红/米黄区分）
- 内容：该时期 `spiritNote` + `spiritTags`（关键词标签样式）
- 引用样式：可加引号/装饰边框强调"精神引文"

### 4.5 照片图集（`images` 非空的场馆）
- 缩略图网格（3-4 列），懒加载
- 点击打开灯箱：`yet-another-react-lightbox`
  - 传入 `slides = images.map(i => ({ src: i.src, alt: i.caption }))`
- 图片说明 `caption` 显示在缩略图下

### 4.6 顶部返回
- 页面顶部/面包屑：`← 返回地图`（跳 `/map`）
- **不做**上一页/下一页场馆切换（MVP 砍掉）

## 5. 灯箱封装（components/common/Lightbox.tsx）

```tsx
// 统一封装，详情页与集锦页共用
<Lightbox
  open={open} onClose={() => setOpen(false)}
  slides={slides} index={index} setIndex={setIndex}
/>
```
- 内部用 `yet-another-react-lightbox`
- 样式：深色遮罩，适配红色主题按钮

## 6. 样式要点

- 内容容器最大宽度约 960px 居中
- 头部区可用深红渐变背景 + 白色文字，正文区米黄底
- 精神区块用金色边框/引号装饰
- 事件时间轴竖线 + 圆点

## 7. 数据依赖

- `venues`、`eventsByVenue`
- 图片：`public/images/venues/<id>/`（压缩后 WebP）
