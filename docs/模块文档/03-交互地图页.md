# 模块文档 03：交互地图页

> 版本：v1.1　日期：2026-08-11　路由：`/map`　MVP：全功能（标记/悬停卡/时间轴/侧栏/飞线/四省强调/弹幕）　布局：仅桌面
>
> 引擎：**MapLibre GL + OpenFreeMap 矢量瓦片**（真实地图，可缩放到街道级）

## 1. 模块职责

全站核心页。以真实矢量地图呈现 13 个场馆（梅园不入地图，为 12 个标记点）及"驻地变迁"时间线，提供标记悬停、时间轴联动、飞线动画、四省强调与弹幕蒙版。也是**场馆详情页的唯一入口**（侧栏列表 + 资料卡）。用户可手动放大查看场馆具体位置。

## 4. 全局状态（useMapState）

React Context，地图页范围内：
- `periodKey: PeriodKey | null` — 当前激活时期
- `setPeriod(key)` — 时间轴/标记/侧栏互动的唯一写入入口
- `hoveredVenueId: string | null` — 悬停资料卡数据

## 5. 地图初始化（MapView）

- 原生 `maplibre-gl`：
  ```ts
  const map = new maplibregl.Map({
    container: divRef.current,
    style: 'https://tiles.openfreemap.org/styles/positron',
    center: [117, 31],
    zoom: 6,
  });
  ```
- 挂载后初始视野 `center [104, 35] zoom 4.5` 覆盖全部标记点（13 场馆、山东临沂在内）
- 主题配色：`map.setPaintProperty` 调整底图（背景米黄、弱化水体/道路色），融入红色主题
- 暴露实例：`useMapInstance` 提供 `flyTo`/`fitBounds`/`project`/`queryRenderedFeatures`
- 清理：组件卸载 `map.remove()`

## 6. 场馆标记层（VenueLayer）

- 数据：`GeoJSON source 'venues'`，10 个 Point（`onMap !== false`），feature 属性含 `id`、`periodKey`、`visitStatus`、`name`、`spiritTags`
- 图层：
  - `circle` 层：`circle-color` 红色 `#B03A2E`；未实践（`visitStatus` ∈ `noVenue`/`pending`）灰色 `#9a9488` + 低透明度（未实践区域标识）
  - 可选 `symbol` 层：场馆编号/名称（小字号）
- 高亮逻辑：
  - 当前时期：`circle-radius` 13 + `circle-color` 金色，`circle-opacity` 1
  - 非当前：`circle-opacity` 0.4；未实践点保持灰色
  - 用表达式（`['==', ['get', 'periodKey'], key]` / `['match', ['get','visitStatus'], ['noVenue','pending'], …]`）实现
- 脉冲动画：`requestAnimationFrame` 循环更新 `circle-radius`/`circle-opacity`（标准 pulsing 方案），仅当前/选中标记启用

## 7. 悬停资料卡（InfoCard）

- React 浮层（非 maplibre popup，便于 CSS Modules 定制）
- 定位：`const pt = map.project(coords)` → 卡片定位于标记旁；边缘翻转（近右/下边缘时反向）
- 内容：场馆名、时期、日期区间、一句话简介、缩略图、精神关键词标签、"查看详情 →"（跳 `/venues/:id`）
- 事件：`map.on('mouseenter'/'mousemove')` + `queryRenderedFeatures` 命中场馆；`mouseleave` 隐藏

## 8. 时间轴滑块（TimeSlider）

- 13 个时期节点横向排布（底部条），含年份/主题（梅园节点保留，点选飞至南京但无标记）
- 激活节点高亮（金色），其余灰
- 交互：
  - 点击节点 → `setPeriod(key)`
  - `map.flyTo({ center: venueCoords, zoom: 9 })` 平滑飞行
  - 高亮该时期标记，淡化其他
  - 侧栏显示 `summary` + `spiritNote`
- 初始定位：MapPage 读取 `location.search` 的 `period` 参数 → 首帧 flyTo

## 9. 右侧栏（VenueSidebar）

- 顶部：当前时期标题 + 摘要（`timeline.summary`）+ 精神关键词（`spiritNote`）
- 场馆列表：8 项（名称 + 城市 + 时期），点击 → 定位标记 + 打开资料卡
- 实地调研场馆加"实地"角标；点击列表项 → 跳详情（或先定位再点卡内"查看详情"）

## 10. 四省省界强调

- 数据：`provinces.json`（鄂/赣/皖/苏）作为 `GeoJSON source 'provinces'`
- 图层：`fill`（`#B03A2E` 透明度 ~12%）+ `line` 描边（`#7B241C` ~50%）→ 视觉强调四省

## 11. 飞线动画（FlyLines）

技术：GeoJSON 线图层 + rAF 动画（不依赖第三方插件）。**完整迁移路线持久常显**。

图层（`MapView` addSourcesAndLayers）：
- `fly-route`：**持久基线路**——完整迁移路线（各段贝塞尔弧线首尾相接成一条 LineString，`buildRoute`），金色虚线低透明度，飞线开启时常显
- `fly-trail`：动画高亮线（rAF 逐帧更新该段弧线 `setData`），金色实线
- `fly-dot`：光点（红色实芯 + 米白描边），随动画移动

动画与交互（`FlyLines`）：
- 进页自动按时间顺序播完整迁移（汉口→…→临沂，每段约 1s，`?period=` 进入则跳过全播）
- **播完 `fly-trail` 固定为整条完整路线（`FULL_ROUTE`）持久保留**
- 时间轴选时期：基线路保持常显，高亮线只播放并保留对应单段，光点落于场馆
- 控制：角落"隐藏飞线/重播飞线"按钮，切换 `fly-route/fly-trail/fly-dot` 三个图层可见性
- 清理：卸载/隐藏/切时期时 `cancelAnimationFrame`

## 12. 弹幕蒙版（DanmakuLayer）

详见《模块文档 06》——地图页内集成：
- 角落"弹幕"开关按钮（默认关）
- 开启后从 `content/testimonials.md` 取预置留言，横向飘过
- `pointer-events: none` 不挡地图；按钮自身 `pointer-events: auto`
- 位置：absolute 覆盖地图容器

## 13. 数据依赖

- `venues`（8 项，街道级 coords/spiritTags/images…）
- `timeline`（8 时期，venueIds/summary/spiritNote/accentColor）
- `testimonials`（预置弹幕）
- `provinces.json`（四省省界）
- `events`（本期地图不直接用，跳详情后加载）

## 14. 性能要点

- 地图页路由懒加载（`React.lazy`）
- maplibre 矢量瓦片按需加载；样式资源缓存
- 飞线 rAF 播放时避免与 hover 冲突；组件卸载取消动画循环、`map.remove()`
